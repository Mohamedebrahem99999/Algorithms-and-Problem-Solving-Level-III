# Problem #15: Count Number in Matrix

## Problem Statement

Write a program to count given number in matrix.

## Example Output

```
Matrix1:
9   1   12
0   9   1
0   9   9

Enter the number to count in matrix? 9

Number 9 count in matrix is 4
```

## Notes

- The program reads a number from the user, then goes through every element of the matrix.
- A counter goes up by one each time `Matrix[i][j]` equals the given number.
- In the example, `9` appears 4 times.
