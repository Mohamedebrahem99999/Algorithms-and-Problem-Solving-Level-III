# Problem #29: Count Small/Capital Letters

## Problem Statement

Write a program to read a string then count small/capital letters in that string.

## Example Output

```
Please Enter Your String?
Mohammed Abu-Hadhoud

String Length = 20
Capital Letters Count= 3
Small Letters Count= 15
```

## Notes

- The program reads a string, then goes through it and counts the capital letters and the small letters separately.
- It also prints the total length of the string, which includes spaces and other characters.
- In the example, the capital letters are `M`, `A`, and `H` (3). The small letters are 15. The remaining 2 characters are the space and the hyphen, which are neither, so `3 + 15 + 2 = 20`.
