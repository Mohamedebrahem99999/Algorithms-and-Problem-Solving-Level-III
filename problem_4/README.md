## Problem #04: Sum Each Column in Matrix

### Description

Write a program to fill a **3x3 matrix** with random numbers, then print each column sum.

### Expected Output

```
The following is a 3x3 random matrix:
 5     1    87
46    12     2
87     2    68

The following are the sum of each col in the matrix:
Col 1 Sum = 138
Col 2 Sum = 15
Col 3 Sum = 157
```
