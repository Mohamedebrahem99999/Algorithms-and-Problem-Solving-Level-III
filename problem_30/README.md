# Problem #30: Count Letters

## Problem Statement

Write a program to read a string and read a character then count the character in that string.

## Example Output

```
Please Enter Your String?
Mohammed Abu-Hadhoud

Please Enter a Character?
m

Letter 'm' Count = 2
```

## Notes

- The program reads a string and a single character, then goes through the string and counts how many times that character appears.
- In the example, the count is case-sensitive: `Mohammed` contains two lowercase `m` letters, and the capital `M` at the start is not counted. A case-insensitive count would give `3`.
