# Problem #11 Compare Two Matrices (Equal or Not)

## Problem Statement

Write a program to compare two matrices and check if they are equal or not.

### Note:

Equal Matrices have the same sum of elementss

## Example Output

```
Matrix1:
06   03   06
04   05   09
03   04   04

Matrix2:
08   09   06
06   08   06
09   03   05

No: martices are NOT equal.
```
