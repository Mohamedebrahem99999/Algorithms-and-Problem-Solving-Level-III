# Problem #45: Convert Line Data to Record

## Problem Statement

Write a program to convertl line data to record and print it:

```
Line Record is:
A150#//#1234#//#Mohammed Abu-Hadhoud#//#079939999#//#5000.000000
The following is the extracted client record:
Account Number: A150
PinCode? 1234
Name? Mohammed Abu-Hadhoud
Phone? 079939999
AccountBalance? 5000
```
