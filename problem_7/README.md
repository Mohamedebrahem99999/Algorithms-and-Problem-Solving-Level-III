# Problem #7

Transpose Matrix

## Problem Statement

Write a program to fill a 3x3 matrix with ordered numbers and print it, then transpose the matrix and print it.

## Expected Output

```
The following is a 3x3 ordered matrix:
1   2   3
4   5   6
7   8   9

The following is the transposed matrix:
1   4   7
2   5   8
3   6   9
```

## Notes

- The matrix is filled with ordered numbers from 1 to 9, row by row.
- Transposing a matrix swaps its rows and columns: the element at `[i][j]` moves to `[j][i]`.
