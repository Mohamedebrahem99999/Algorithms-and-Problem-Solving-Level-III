# Problem #17: The Number Existing in the Array

## Problem Statement

Write a program to check if a given number exists in matrix or not.

## Example Output

```
Matrix1:
77   5    12
22   20   1
1    0    9

Please Enter the number to look for in matrix? 77

Yes it is there.
```

## Notes

- The program reads a number from the user, then searches the matrix for it.
- If any element `Matrix[i][j]` equals the given number, the number exists and the search can stop.
- If no element matches after checking the whole matrix, the program should print a message saying the number is not there.
