# problem #10 	Sum of All Numbers in a Matrix

## Problem Statement

Write a program to fill a 3x3 matrix with random numbers and print its elements, then write a function to sum all numbers in this matrix and print it.

## Example Output

```
Matrix1:
04   08   06
03   10   07
08   08   10

Sum of Matrix1 is: 64
```

## Notes

- Check: `(4 + 8 + 6) + (3 + 10 + 7) + (8 + 8 + 10) = 18 + 20 + 26 = 64`.
