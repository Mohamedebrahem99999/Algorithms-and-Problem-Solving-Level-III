# Problem #03: 3x3 Random Matrix Row Sums (Separate Array)

Write a program to fill a 3x3 matrix with random numbers, then sum each row in a separate array and print the results.

## Expected Output

```
The following is a 3x3 random matrix:
53      43      6
65      83      48
64      30      36

The following are the sum of each row in the matrix:
Row 1 Sum = 102
Row 2 Sum = 196
Row 3 Sum = 130
```
